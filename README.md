🟡 Pac-Man 3D

«Una nueva dimensión para el clásico Pac-Man. 👻🎮»

🎮 Acerca del proyecto

Pac-Man 3D es un ambicioso fangame inspirado en la franquicia Pac-Man, desarrollado por EituProGamer.

El objetivo del proyecto es llevar la experiencia clásica de Pac-Man a un mundo completamente tridimensional, combinando elementos clásicos con nuevas mecánicas, enemigos, jefes, ciudadanos rescatables y desafíos cada vez más intensos.

Este proyecto fue desarrollado como un juego web y posteriormente convertido en una aplicación APK para Android.

---

✨ Características

- 🟡 Jugabilidad clásica de Pac-Man reinventada en 3D
- 👻 Fantasmas clásicos y nuevos enemigos

- 👑 Sistema de coronas al superar niveles especiales

- 🌀 Portales y mecánicas especiales

---

👹 Bosses

Pac-Man 3D no solo consiste en escapar de fantasmas.

Durante la aventura aparecerán poderosos jefes que pondrán a prueba tus habilidades. Cada Boss Stage incluye desafíos especiales, mecánicas únicas y objetivos que deberás completar para avanzar.

El desafío final lleva la experiencia al límite con enemigos gigantes y una batalla épica.

---

🏙️ Pac-City

Una de las características más importantes del juego es Pac-City.

A medida que avanzas en el juego puedes rescatar ciudadanos atrapados. Los ciudadanos rescatados pasan a formar parte de Pac-City y pueden ayudarte durante la aventura.

Esto hace que la progresión no se trate solamente de avanzar niveles: ¡también estás construyendo y recuperando una ciudad! 🟡🏙️

📱 APK para Android

🛠️ Tecnologías utilizadas

El proyecto utiliza tecnologías web modernas para crear una experiencia de juego tridimensional:

- HTML5
- CSS3
- JavaScript
- Three.js
- IndexedDB
- PWA
- Web Audio API

La versión Android fue creada empaquetando la experiencia web como una aplicación APK.
